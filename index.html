Polyfork Games

Three small three.js games, each built to teach a different set of game-programming ideas. Every model comes from Polyfork's free low-poly catalogue. Each game folder has a LEARN.md that walks through its code.

Game 1 · Beginner

Retro Rush

An endless three-lane highway dodger. Weave through traffic, burn nitro, chase near misses.

  • game loop & delta time
  • loading GLB models
  • treadmill world
  • object pooling
  • box collision
  • screen shake
Game 2 · Intermediate

Orbit Defense

A top-down twin-stick shooter. Guard the beacon against waves of raiders, mines and a bomber boss.

  • vectors & mouse aiming
  • projectiles
  • steering AI
  • wave spawning
  • instanced particles
  • hit-stop
Game 3 · Advanced

Crypt Crawler

A turn-based dungeon crawl. Every floor is generated from a seed: fight, loot, and go deeper.

  • procedural generation
  • seeded RNG
  • A* pathfinding
  • turn scheduler
  • enemy FSM
  • skinned animation
3D models by Polyfork (mesh files CC BY 4.0). Kit covers from the polyfork-catalog. See each game's CREDITS.md.
